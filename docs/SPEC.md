# Smooth Reading — Core Specification

Smooth Reading is an open-source (Apache-2.0) implementation of *guided fixation reading*: the leading letters of every word are emphasised (typically in bold or a distinct weight/color) so the eye lands on an artificial fixation point and the brain completes the rest of the word.

The technique is similar to commercial fixation-reading products, but this project is an independent, clean-room implementation.

This specification is the canonical contract governing every port and package in the monorepo. The core algorithm is deterministic and language-agnostic so that all runtime implementations (TypeScript, Swift, Kotlin, Python) produce byte-identical output for shared test fixtures.

---

## 1. Terminology

| Term | Definition |
| --- | --- |
| **Word** | A maximal sequence of letters, digits, and combining marks, optionally joined by internal apostrophes, as produced by the tokenizer (§3). Hyphens act as separators; for example, `well-known` is two words. |
| **Fixation** | The emphasised leading prefix of a word. |
| **Fixation Strength (`fixation`)** | An integer from `1` to `5` specifying what proportion of each word is emphasised. Default: **`3`**. |
| **Saccade Interval (`saccade`)** | The spacing between emphasised words. `saccade = 1` emphasises every word, `saccade = 2` emphasises every second word, etc. Default: **`1`**. |
| **Token** | A discrete element of segmented text: either a **word** (with computed split indices) or a **separator** (whitespace, punctuation, markup tags, emoji). |

## 2. Fixation length algorithm

Given a word of `n` user-perceived characters (**extended grapheme clusters**, not UTF-16 code units or raw bytes) and fixation strength `s ∈ {1, 2, 3, 4, 5}`:

```
ratio     = { 1: 0.20, 2: 0.35, 3: 0.50, 4: 0.65, 5: 0.80 }[s]
prefixLen = clamp( round_half_up(n * ratio), 1, n )   // for n >= 1
```

### Evaluation order & Suppression rules

Rules are evaluated in strict priority order. If any suppression condition is met, the word receives **no fixation** (`prefixLen = 0`):

1. **Numeric suppression**: Words consisting entirely of decimal digits (`\p{Nd}`) receive no fixation unless `emphasizeNumbers` is explicitly set to `true`.
2. **Length suppression**: Words with fewer than `minWordLength` grapheme clusters (default: `1`) receive no fixation.
3. **Single-character words (`n == 1`)**: Single-character words are emphasised **only if** `s >= 3`. At strength 1 or 2, single-character words receive no fixation. This rule applies uniformly to all scripts, including single-character words generated by ICU segmentation (e.g. Chinese `我` or Japanese particles like `は`).
4. **General formula**: In all other cases, `prefixLen = clamp(round_half_up(n * ratio), 1, n)`.
5. **Internal characters**: Internal apostrophes count as grapheme clusters (e.g. `don't`, `n = 5` → prefix `don`). Hyphens act as word separators, splitting hyphenated compounds into distinct words (`well-known` → `<b>we</b>ll-<b>kno</b>wn`).

> [!NOTE]
> A word that receives no fixation still consumes a saccade index (§4) and is emitted as plain text (never wrapped in `restTag`).

### Half-up rounding

`round_half_up(x)` is defined as `floor(x + 0.5)`. To prevent floating-point drift across platforms, implementations MUST compute rounding using integer arithmetic:

$$\text{prefixLen} = \lfloor \frac{n \times \text{percent} + 50}{100} \rfloor \quad \text{where } \text{percent} \in \{20, 35, 50, 65, 80\}$$

Ports must use this exact integer formula (never banker's rounding or floating-point division) to ensure cross-language byte parity.

### Reference calculations (Default strength 3)

| Word | Grapheme count ($n$) | Fixation prefix | Emitted text |
| --- | --- | --- | --- |
| `a` | 1 | `a` | `<b>a</b>` |
| `to` | 2 | `t` | `<b>t</b>o` |
| `the` | 3 | `th` | `<b>th</b>e` |
| `read` | 4 | `re` | `<b>re</b>ad` |
| `smooth` | 6 | `smo` | `<b>smo</b>oth` |
| `reading` | 7 | `read` | `<b>read</b>ing` |
| `2024` | 4 | *(none)* | `2024` |
| `naïve` | 5 | `naï` | `<b>naï</b>ve` |

### Custom override

An optional callback may override the fixation length computation entirely:
`fixationLength(word: string, graphemeCount: number, options) => number`
The return value is truncated to an integer and clamped to `0..n`.

## 3. Tokenizer & Word boundary specification

### Primary segmentation: ICU / `Intl.Segmenter`
Where available, implementations MUST use standard Unicode break iterators:
- Web / Node: `Intl.Segmenter(locale, { granularity: "word" })`
- Swift: `String.enumerateSubstrings(.byWords)` or `CFStringTokenizer`
- Android: `android.icu.text.BreakIterator`

Segments with `isWordLike === true` (or equivalent) are classified as words; all other segments are classified as separators. This provides dictionary-based word boundary detection for non-space scripts (Chinese, Japanese, Thai, Lao, Khmer, Burmese).

### Fallback segmentation: Unicode regex scanner
When a platform ICU engine is unavailable (e.g. Python standard library or environments lacking `Intl.Segmenter`), implementations MUST use the canonical regular expression:

```regex
[\p{L}\p{N}][\p{L}\p{N}\p{M}]*(?:['’][\p{L}\p{N}\p{M}]+)*
```

- Contractions with apostrophes (`'`, `’`) remain unified; hyphens split into distinct words.
- A word **never** starts with a combining mark. Any combining mark or variation selector following a separator (such as U+FE0F in emoji sequences like `❤️`) remains attached to the separator (UAX #29 rule WB4).
- Continuous runs of CJK ideographs (`\p{Script=Han}`, Hiragana, Katakana, Hangul) or Thai characters are treated as a single word per **continuous run**, and standard §2 fixation calculations apply to that run.

### Grapheme cluster resolution
Grapheme clusters are evaluated according to Unicode UAX #29 extended grapheme cluster boundaries:
1. **Unicode 15.1 Rule GB9c**: Consonant conjuncts linked by a virama in Devanagari, Bengali, Gujarati, Oriya, Telugu, and Malayalam (such as `क्ष`) form an indivisible cluster.
2. **Hangul Syllable Composition**: Decomposed Hangul jamo sequences (`L* (V+ | LV | LVT) T*`) compose into single syllabic clusters.
3. **Combining Sequences**: Base characters plus following combining marks (general categories `Mn`, `Mc`, `Me`) and zero-width joiners (ZWJ) remain unified.
4. **CR+LF**: Carriage return and line feed pairs count as single clusters.

## 4. Public API (TypeScript / Core)

```ts
export interface SmoothOptions {
  fixation?: 1 | 2 | 3 | 4 | 5;        // default: 3
  saccade?: number;                     // default: 1, integer >= 1
  minWordLength?: number;               // default: 1
  emphasizeNumbers?: boolean;           // default: false
  locale?: string;                      // BCP-47 language tag
  fixationLength?: FixationLengthFn;   // custom fixation override
}

export type Token =
  | { type: "word"; text: string; fixation: number; fixationText: string; restText: string }
  | { type: "separator"; text: string };

export function tokenize(text: string, options?: SmoothOptions): Token[];

export interface HtmlOptions extends SmoothOptions {
  tag?: string;                         // default: "b"
  className?: string;                   // optional CSS class
  restTag?: string;                     // optional tag for remainder
  restClassName?: string;
  ignoreHtmlTags?: boolean;             // default: true (preserves existing markup)
  skipTags?: string[];                  // default: ["code","pre","script","style","kbd","samp","textarea"]
}

export function toHtml(text: string, options?: HtmlOptions): string;
export function applyToElement(root: Element, options?: DomOptions): () => void;
export function createTransformStream(options?: HtmlOptions): TransformStream<string, string>;
```

### Behavioral guarantees

1. **HTML Escaping**: `toHtml` safely escapes `<`, `>`, `&`, and `"` in emitted text. Existing tags pass through unmodified when `ignoreHtmlTags: true`.
2. **Range Clamping**: Out-of-range values are clamped automatically, never throwing or failing silently (`fixation` outside 1–5 clamps to `1` or `5`; `saccade < 1` clamps to `1`).
3. **Saccade Counting**: Saccade intervals count word tokens only. The first word of the input always receives a fixation (index 0 mod saccade). Every word token consumes an index, including numeric words and short words. Text within skipped tags is never tokenized and consumes no saccade index.
4. **No Nested Emphasis**: When `ignoreHtmlTags: true`, the specified `tag` and `restTag` are automatically added to the skip list, preventing double-wrapping of existing markup.
5. **Entity Handling**: Existing HTML character references (`&amp;`, `&#x27;`) pass through untouched and act as word boundaries. Bare `&` characters that do not start valid entities are escaped.

## 5. CSS & Presentation

Emphasis is purely presentational. Implementations emit semantic-neutral markup and supply an optional stylesheet (`styles.css`):

```css
.sr-fixation { font-weight: 700; }
.sr-rest     { opacity: var(--sr-rest-opacity, 1); }
```

Consumers may configure `tag: "span"` and `className: "sr-fixation"` to style fixations via color, font weight, or underline.

## 7. Non-goals

- Zero external network dependencies, zero telemetry, and zero runtime dependencies in core packages.
- Zero medical or speed-reading claims; citations to scientific studies are presented neutrally.
